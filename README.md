# Antojadas — Galletitas Saludables

Sitio web estático de Antojadas, listo para publicar con GitHub Pages.

## Publicar en GitHub Pages

1. Crear un repositorio público en GitHub (por ejemplo, `antojadas`).
2. Subir **todo el contenido de esta carpeta** manteniendo la carpeta `assets`.
3. Ir a **Settings → Pages**.
4. En **Build and deployment**, elegir **Deploy from a branch**.
5. Seleccionar la rama `main` y la carpeta `/ (root)` y guardar.
6. Esperar a que GitHub Pages publique el sitio.

## Dominio personalizado

El archivo `CNAME` ya está preparado para `antojadas.com.ar`. Una vez registrado el dominio en NIC Argentina, se deben configurar en NIC los DNS que indique GitHub Pages y verificar el dominio desde **Settings → Pages → Custom domain**.
